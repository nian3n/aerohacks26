# Inital Plan and Brainstorming

## Understanding the project
Understanding the goal of the challenge is the most important part of the design process, it's what sets the requirement of project.

## Requirments 
 - Hover a drone in the center of space for 60 sec
 - Use optimized computer vision to detect drone
 - stereo triangulation to be have depth and be able to compute a 3D grid
 - Filtering, avoid noise and oscilllations
 - implementing a better method for PID calibration 

## Main tasks to implement
1- Detect Drone using openCV
2- implement stereo triangulation to add depth
3- Kalman Filter
4- Use threading to optimise camera response and avoid reliance on other codeblocks
5- implement mode 2 for better PID response 
6- implement mode 3 
7- implement mode 4 
8- step prediction
